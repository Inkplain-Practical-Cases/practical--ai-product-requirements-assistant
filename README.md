# AI Product Requirements Assistant

A product owner needs stakeholder narratives transformed into reviewable user stories, measurable acceptance criteria, data flows, and grounded system-design options.

An Inkplain practical case: a real project built step by step.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inkplain-Practical-Cases/practical--ai-product-requirements-assistant.git
cd practical--ai-product-requirements-assistant
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
